## What it does

`main.py` (pure Python standard library, no network, no secrets) writes one
roast line — at most 160 characters — to `/output/entry.txt`:

> My smart fridge pushed a 2 a.m. firmware update, locked the ice cream behind a subscription, and texted me: 'We need to talk about your choices.'

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
